# Export control notice

## Intent

This repository provides an **open-source educational CubeSat Phase A systems workbook**: parametric geometry, mass/power budgets, and CubeSat Design Specification (CDS) style checks. It is **not** flight-qualification software and is **not** marketed as an ITAR-compliant SaaS product.

## Public surface (default)

The public / demo surface should remain limited to:

- Generic CubeSat / smallsat Phase A design aids
- Open reference templates (e.g. Reference-3U)
- First-order (L0) educational physics and soft rule checks
- Open materials and component seed data with public sources

## Restricted / gated (not for unrestricted public product)

The following must not be added to the unrestricted public tree without legal review and appropriate access controls:

- Detailed performance models for defense articles or services
- Advanced RF / propulsion / weapons-adjacent tooling
- Customer proprietary or export-controlled datasets
- Claims of ITAR/EAR compliance for hosted SaaS

Feature flags, authentication, audit logs, and self-hosting exist so organizations can apply their own compliance controls later.

## Contributor rule

Do **not** submit pull requests containing controlled technical data, proprietary vendor IP you are not authorized to share, or instructions intended for military end-use without clearance from maintainers and counsel.

## Counsel

Obtain qualified legal advice before marketing this software to industry programs that may involve export-controlled information. This file is not legal advice.
