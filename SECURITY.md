# Security Policy

## Supported versions

This project is in early development. Security fixes are applied on a best-effort basis to the `main` branch.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email the maintainers via the GitHub account that owns this repository, or use [GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability) if enabled on this repository.

Include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Any suggested fix (optional)

We will acknowledge reports when possible. There is no guaranteed SLA at this stage.

## Scope notes

- Do not commit API keys, cloud credentials, or proprietary / export-controlled datasets.
- The public product surface is intended for **educational CubeSat Phase A** workflows. See [EXPORT_CONTROL.md](EXPORT_CONTROL.md).
