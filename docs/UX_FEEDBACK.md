# UX design-loop notes (2026-07-15)

Simulated first session: university CubeSat student opening the workbook.

## Friction found

1. No guided “what next” after landing — toolbar noise before purpose
2. Scorecard / margins buried in tabs — health not always visible
3. “Reset Reference-3U” swapped the open Mk5 visual for blocky parametric
4. Envelope edits don’t reshape imported STEP — felt broken without copy
5. VCRM/ICD read-only — systems tab felt dead
6. No camera fit after orbiting away
7. Narrow layout + missing webfonts
8. Export STEP disabled with unclear recovery

## Shipped in this loop

- Always-on status strip (mass / PV / power margin / CDS)
- Guided path coach with deep-links into tabs
- Split **Reset numbers** vs **Show parametric frame**
- Explicit “numbers ≠ imported mesh” copy on Design
- Editable VCRM status + project v2 persistence (doc + systems)
- Fit view control; wider shell; IBM Plex loaded
- Clickable scorecard rows → relevant tab

## Loop 2 shipped

- CDS envelope ghost wireframe over the 3D model (numbers → visible box)
- One-click “Apply panel H …” when power margin is weak
- ICD open-item checkboxes (persisted in project v2)

## Loop 3 shipped

- CDR HTML export (browser Print → PDF for advisors)
